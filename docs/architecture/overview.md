# MacLean Architecture Overview

The canonical architecture now lives in [docs/ARCHITECTURE.md](../ARCHITECTURE.md). This file remains as a compatibility link for earlier repository references.

The implementation stays language-independent because the repository has no established source runtime or build system. Read-only discovery and telemetry are the first work; system-changing controls remain out of scope until their interfaces and rollback paths are documented.
